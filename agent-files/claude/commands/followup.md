Load and display the active task's follow-up instructions:

**Usage:**
- `/followup` - Read follow-up instructions from the task's `followup.txt`

The follow-up content lives next to `instructions.txt` in the task definition
directory and describes what "following up" means for the active task type
(for example, addressing a review posted on the MR opened by a `develop` task).
